# Lean Fitness OS

A React/Vite rebuild of the personal fitness tracker.

## Included
- Dashboard with checklist, calories, protein, and water goals
- Meal auto-build and meal library
- Meal reordering and removal
- Historical and future calendar planning
- Weight, workout, walking, notes, water ounces/liters
- Editable nutrition goals
- Local browser storage
- Placeholder modules for groceries and progress analytics

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Netlify
Deploy the generated `dist` folder, or connect the project repository and use:
- Build command: `npm run build`
- Publish directory: `dist`
